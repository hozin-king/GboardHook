# GboardHook-NanashiTheNameless

**Semua kredit untuk <https://github.com/chenyue404/GboardHook>. Ini adalah fork yang dimodifikasi dan diterjemahkan untuk pemakaian pribadi**

Mengubah jumlah item clipboard Gboard yang ditampilkan dan waktu simpannya

enable_clipboard_entity_extraction dan enable_clipboard_query_refactoring memengaruhi jumlah entri clipboard yang bisa dibaca. Prinsipnya belum jelas, dan kode kuncinya belum ditemukan, jadi untuk saat ini hanya bisa di-hardcode ke false
